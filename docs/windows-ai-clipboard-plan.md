# Windows AI 增强剪贴板方案

## Mac 灵动岛需求的 Windows 转译

MacBook 的“灵动岛核心入口”在 Windows 上转译为：
- 顶部轻量置顶条：作为低打扰、随时可见的收集入口
- 系统托盘：作为常驻控制入口
- 全局快捷键：作为快速唤起主界面和粘贴历史的入口

目标体验保持一致：用户浏览网页和资料时，复制即收集，必要时通过顶部入口或快捷键快速查看、搜索、处理，不打断当前阅读流。

## 能力分层

### 已落地
- 自动收录文本和图片剪贴内容
- 自动识别文本、图片、链接、Markdown 内容类型
- 自动过滤低信息密度内容，如语气词、零散字符、重复无意义字符
- 支持自然语言式搜索，例如“最近的链接”“上周 agent 文章”“Markdown 笔记”
- 支持智能清理建议，识别重复文本、重复内容和低信息密度内容
- 支持对文本内容生成 AI 处理提示，包括总结、润色、翻译、问答
- 顶部置顶条支持多主题切换

### 下一步建议
- 接入 OpenAI 或兼容 API，直接在应用内完成总结、润色、翻译、问答
- 为剪贴内容生成 embedding，实现真正语义搜索
- 增加清理建议的预览和分组确认
- 增加浏览器来源、窗口来源、网页标题等上下文记录
- 增加“收集篮”或“学习流”模式，让用户围绕一个主题连续收集和探索

## 当前 AI 策略

在没有 API Key 的情况下，应用先提供本地可用的智能底座：
- 规则分类
- 噪声过滤
- 自然语言搜索意图解析
- 清理建议
- AI 提示生成

后续接入模型后，可直接复用这些数据结构和入口，把“AI 提示生成”升级为“AI 结果生成”。
